How to Setup Episodai in Cline

By Lalith Alpuri (@lalithbuilds) • Updated September 2026


Cline (the leading open-source autonomous coding agent for VS Code) supports Model Context Protocol (MCP) servers. Adding Episodai gives Cline long-term persistent memory across complex refactoring tasks.


Configuration in Cline Settings

Open Cline in VS Code, navigate to the MCP Servers tab, and click Configure MCP Servers. Add the following block:


{
  "mcpServers": {
    "episoda": {
      "command": "uvx",
      "args": ["episodai"]
    }
  }
}

Key Advantages for Cline Agents

  • Prevent Memory Rot: Cline automatically flags and recalls past debugging decisions so it never repeats the same mistake twice.
  • Bi-Temporal Knowledge Graph: Cline queries relationships between modified files and architectural constraints using 15 specialized tools.
  • Zero Setup: Runs seamlessly via uvx without virtual environment management.
