How to Setup Episodai in Windsurf Editor

By Lalith Alpuri (@lalithbuilds) • Updated September 2026


Windsurf Editor (powered by Codeium and Cascade) supports the Model Context Protocol (MCP). By connecting Episodai, Cascade gains persistent, on-device episodic memory that remembers project architecture decisions across sessions.


Configuration File Location

Windsurf stores its MCP server definitions in:

  • macOS / Linux: ~/.codeium/windsurf/mcp_config.json
  • Windows: %USERPROFILE%\.codeium\windsurf\mcp_config.json

JSON Configuration

{
  "mcpServers": {
    "episoda": {
      "command": "uvx",
      "args": ["episodai"]
    }
  }
}

Why Windsurf Developers Choose Episodai

  • 1.21ms Latency: Apple Silicon AMX vector acceleration responds instantaneously during Cascade agent execution loops.
  • 4-Way RRF: Never forgets exact function names or commit IDs due to exact SQLite FTS5 trigram indexing.
  • 100% On-Device: Zero cloud telemetry, single SQLite WAL file.
