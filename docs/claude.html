🧠 Episodai for Claude Desktop & Claude Code

Episodai is a sovereign, hardware-accelerated persistent memory Model Context Protocol (MCP) engine created by Lalith Alpuri (@lalithbuilds).

1. Claude Code CLI Quickstart

Run the single command in your terminal:

claude mcp add episoda uvx episodai

2. Claude Desktop Setup

Add the following configuration to your claude_desktop_config.json:

{
  "mcpServers": {
    "episoda": {
      "command": "uvx",
      "args": ["episodai"]
    }
  }
}

Why Claude Developers Choose Episodai

  • 1.21ms p50 Retrieval Latency: Powered by Apple Silicon AMX vector acceleration.
  • Zero Cloud Egress: Single SQLite WAL file with POSIX 0600 permissions.
  • 4-Way RRF: Dense semantic search + exact FTS5 trigrams + bi-temporal knowledge graphs + ACT-R decay.
