# Sharing EpisodAI responsibly

Use the canonical [EpisodAI repository](https://github.com/lalithbuilds/episodai) and [project page](https://lalithbuilds.github.io/episodai/) when describing the project. The creator is [Lalith Alpuri](https://lalithbuilds.github.io/), also searchable as Alpuri Lalith. Older listings may still use the former project label Engram Alpha.

Lead with a working local demo, clear MCP client setup, and a reproducible test or benchmark command. Explain that EpisodAI is a local AI memory MCP server with SQLite-backed storage and retrieval workflows. Distinguish it from the smaller [Episoda Core MCP](https://github.com/lalithbuilds/episoda-core-mcp) project.

When sharing measurements, include the command, dataset, hardware, and limitations. Avoid claims such as “zero dependency,” “infinite memory,” or universal sub-millisecond retrieval that the repository cannot substantiate. Refresh stale third-party directory entries through their normal owner process. Seek real developer feedback rather than purchased stars.
